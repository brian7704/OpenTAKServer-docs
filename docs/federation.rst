Federation
==========

As of version 1.8.0, OpenTAKServer includes initial support for federating with other servers.

What's Currently Supported
--------------------------

-  Outgoing connections to FedHub and the GOTS takserver
-  Group Mapping

Limitations
-----------

All of the features listed here will be supported in a future version of OpenTAKServer

-  Does not accept incoming federation connections
-  No support for missions
-  Tokens
